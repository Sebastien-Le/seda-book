## About SEDA

SEDA (*Sensory Evaluation Data Analysis*) is a jamovi module dedicated to sensory and consumer data analysis. The companion covers:

- QDA data — characterisation of the sensory space
- QDA data — multivariate representation with confidence ellipses
- CATA data
- JAR data
- Napping
- Free sorting
- Preference mapping

The guide is designed to connect the jamovi interface with the statistical logic of each method and, when useful, with the corresponding R workflow.
