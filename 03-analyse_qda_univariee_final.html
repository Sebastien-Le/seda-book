Analyse univariée de données de type QDA (Quantitative Descriptive Analysis)

L’objectif de cette partie est de vous aider à comprendre ce qui se cache derrière les fonctions du module SEDA dédiées à la caractérisation d’un espace produits décrit par des données de type QDA.

Un peu de théorie

Comme jamovi est une interface graphique permettant d’utiliser R, toutes les analyses dans jamovi sont effectuées en R. Nous allons donc vous montrer comment les différents résultats sont obtenus directement avec R.

Prenons l’exemple du parfum analysé dans le fichier jamovi qda_univariate_description.omv.

Du côté de jamovi et du module SEDA

Comment le module SEDA caractérise-t-il un espace produits?

Analyses univariées - ANOVA

La fonction de caractérisation génère deux types de résultats :

  1. Une liste d’attributs discriminants (effet Produit significatif),
  2. Une description individuelle de chaque produit par ses attributs caractéristiques (\(\alpha_i\) significativement différent de 0).

Modèle utilisé :

\[ Y_{ij} = \mu + \alpha_i + \beta_j + \epsilon_{ij}, \quad \sum_i \alpha_i = 0 \]

Les attributs sont triés selon leur p-valeur croissante. Cela permet d’identifier les descripteurs sensoriels les plus discriminants.

Ainsi, le chocolat 1 est particulièrement amer et peu sucré, en comparaison aux autres.
